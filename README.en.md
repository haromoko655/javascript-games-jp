# Brain Busters — Japanese Edition

This is the Japanese edition of a collection of browser-based puzzle and brain-training games. Built with Vue 3 and Vite, it includes 27 games such as Sudoku, Minesweeper, and Connect Four.

This edition is based on [muthuspark/javascript-games](https://github.com/muthuspark/javascript-games). You can play the original English version at [games.muthu.co](https://games.muthu.co).

[日本語版のREADMEはこちら](README.MD)

## Games

| Category | Games |
|---|---|
| Puzzles and logic | Sudoku, Minesweeper, Sliding Puzzle, Latin Square, Magic Square, N-Queens, Knight's Tour, Lights Out, Mastermind, Bulls and Cows, Set, Tangram, Binary Puzzle, Sokoban |
| Strategy | Tic-Tac-Toe, Connect Four, Nim, Dots and Boxes, Hex |
| Words and learning | Word Search, Hangman, Typing Speed Test |
| Memory and reflexes | Memory Match, Simon Says, Reaction Time Test, Whack-a-Mole |
