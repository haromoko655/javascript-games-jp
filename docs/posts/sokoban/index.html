倉庫番 - 箱押しパズル

箱を押してすべての目的地に運ぶ、日本生まれの定番パズルです。隅に押し込むと戻せないので、手順をよく考えましょう。

パズル論理定番
レベル1：チュートリアル
手数： 0押した回数： 0

遊び方

  • すべての箱（茶色のマス）を目的地（赤い丸）まで押します
  • 矢印キーまたはWASDキーで移動します
  • UキーまたはCtrl+Zで一手戻します
  • Rキーで面をやり直します
  • 箱が目的地に乗ると緑色になります

よくある質問

矢印キーまたはWASDキーで青いプレイヤーを動かし、箱を押して目的地へ運びます。箱を引くことはできません。隅に押した箱は戻せないため、手順をよく考えましょう。

UキーまたはCtrl+Zで手を戻すか、Rキーで面をやり直せます。一手戻す機能では、過去の手を順に戻せます。

チュートリアルから難しい問題まで、全10面あります。進むにつれて計画性と戦略が必要になります。

「倉庫番」は箱を運ぶ人を意味します。ゲームは1981年に今林宏行氏が制作し、世界中で親しまれるパズルになりました。
